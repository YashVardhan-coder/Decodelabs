# DecodeLabs — Cyber Security Projects

A collection of lightweight, zero-dependency Python tools developed as part of the DecodeLabs Cyber Security Internship.

---

## 📁 Projects Overview

| Project | Description | Tech | Detailed Docs |
|---|---|---|---|
| **[Project 1: Password Strength Checker](./project%201)** | CLI tool that analyzes password resilience based on length and character entropy (uppercase, lowercase, digits, symbols). | Python 3.8+ | [Read Project 1 Docs](./project%201/README.md) |
| **[Project 2: Caesar Cipher Tool](./project%202)** | Interactive CLI for encryption, decryption, IPO cycle verification, and brute-force cryptanalysis using modular arithmetic. | Python 3.8+ | [Read Project 2 Docs](./project%202/README.md) |

---

## 🚀 Quickstart

### Prerequisites
- Python 3.8 or higher installed on your system.
- Standard libraries only (no third-party packages required).

### Running Project 1
```bash
python "project 1/main.py"
```

### Running Project 2
```bash
python "project 2/main.py"
```
